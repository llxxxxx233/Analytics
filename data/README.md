# 数据字段与口径说明

## 数据分类

| 目录 | 用途 | 说明 |
|---|---|---|
| `sample/` | 模拟数据 | 仅用于功能演示与测试，**非真实经营数据**，界面中会显著标注 |
| `raw/` | 真实 / 脱敏数据 | 个人订单、客户与合作方信息需脱敏后使用，**不提交到版本库** |

## 标准字段

导入时按字段别名自动识别（兼容中英文列名），未识别的列会保留并在质量报告中提示。

### 订单明细（必填）

| 标准字段 | 说明 | 别名示例 |
|---|---|---|
| `order_date` | 订单日期 | 订单日期 / 下单日期 / date |
| `product_name` | 商品名称 | 商品名称 / 商品 / 品名 |
| `quantity` | 销售数量（件） | 数量 / 销量 / qty |
| `amount` | 成交金额（总价，非单价） | 成交金额 / 销售额 / 实付金额 |
| `channel` | 销售渠道 | 渠道 / 销售渠道 / 平台 |
| `order_id` | 订单号（可选） | 订单号 / order_id |

### 商品信息（可选）

`product_name`（商品名称，必填）、`ip`、`category`（品类）、`spec`（规格）、`cost`（成本）。

### 库存记录（可选）

`product_name`（必填）、`stock`（当前库存，必填）、`cost`（成本）。

## 计算口径

- **销售额 / 销量**：按订单行直接汇总，`amount` 视为该行成交总额。
- **库存覆盖天数** = 当前库存 ÷ 日均销量；日均销量按订单表中「最早到最晚日期」覆盖的天数估算，仅作为参考。
- 缺失的金额、数量、日期等字段保留为缺失值（NaN），**不自动当作 0**；质量报告会提示影响。
- 关键指标由 `src/analytics.py` 用确定性代码计算，大语言模型只负责解释、不产出数字。
